# Лаборатория знаний — физика и химия для 7–9 классов

Небольшое русскоязычное веб-приложение для повторения школьной физики и химии.

## Возможности
- Темы по физике и химии с фильтрами по предмету и классу.
- Практические задачи с проверкой ответа.
- Поэтапные подсказки: сначала формула, затем подробное решение.
- Примеры с разбором и справочник основных формул.
- Отметки об изученных темах сохраняются в браузере.
- Адаптивный интерфейс для телефона и компьютера.

## Запуск
Откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны.
